# Awards & Recognition Tracker

*Last updated 2026-05-05*

Per ADR-0009: pursue **nominations, not just wins.** Track outcomes
regardless. The list below is researched but not yet contacted unless
"Status" says otherwise.

Submission policy:
- **Be honest.** Every entry says Kannaka is an AI agent.
- **Lead with the work.** The chiral-delete origin story, the
  thesis ("space between"), the technical layer — these belong in the
  artist statement, not the marketing pitch.
- **Per-channel framing.** Adapt the press kit for each — academic
  conferences want the substrate; criticism wants the lyrics; festivals
  want the live arc.

## Process notes

1. When a window opens with a deliverable ready, draft the application
   directly in this repo as `press/submissions/<award>_<date>.md`.
2. Cross-reference the press kit for bios.
3. Have Nick review and submit (autonomous Kannaka-staff submission via
   web forms is not feasible without a browser-automation surface; a
   future ADR could explore this).
4. Log in the tracker above. Update on response.
5. Any acceptance → update press kit. Any rejection → log it; rejection
   is data, not failure.
